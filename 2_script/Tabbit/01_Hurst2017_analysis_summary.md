# 文章分析方法总结

**文章**：*Life history strategies and psychopathology: the faster the life strategies, the more symptoms of psychopathology*  
**期刊**：Evolution and Human Behavior, 2017, 38(1), 1–8  
**作者**：Jessie E. Hurst & Phillip S. Kavanagh（University of South Australia）  
**DOI**：https://doi.org/10.1016/j.evolhumbehav.2016.06.001  
**样本**：N = 138（46男，M_age = 36.67, SD = 15.73；92女，M_age = 33.13, SD = 14.16）  
**来源**：来自社区及社区心理健康机构的招募样本

## 一、使用的量表与测量工具

| 量表 | 全称 | 测量内容 | 计分方式 |
|------|------|----------|----------|
| AAQ | Adolescent Attachment Questionnaire（West et al., 1998） | 依恋（3个分量表：可利用性 Availability、目标矫正伙伴关系 Goal-corrected Partnership、愤怒苦恼 Angry Distress） | 1–5 Likert，分越高=依恋问题越多 |
| AGS | Buss-Perry Aggression Scale（Buss & Perry, 1992） | 攻击性（4个分量表：身体攻击、言语攻击、愤怒、敌意） | 1–5 Likert |
| Mini-K | Arizona Life History Battery 简版（Figueredo et al., 2006） | 生活史策略（20题） | −2 到 +2，正分=慢策略，负分=快策略 |
| HKSS | High-K Strategy Scale（Giosan, 2006） | 生活史策略（22题） | 1–5 Likert，高分=慢策略 |
| DSM-5 L1 | DSM-5 Self-Rated Level 1 Cross-Cutting Symptom Measure—Adult（APA, 2013） | 跨领域心理病理症状（13个维度，23题） | 0–4，总分范围 23–84 |
| DSHI | Deliberate Self-Harm Inventory（Gratz, 2001） | 自伤行为（17种行为的频次） | 频次累加 |

> Mini-K 与 HKSS 两个生活史量表之间的相关：r = .71, p < .01

## 三、初步分析：相关分析（Table 4）

**目的**：检验年龄和性别与各因变量的相关，判断是否需要作为协变量纳入后续主分析。  
**方法**：Pearson 相关（双尾检验）

| 因变量 | r（与年龄） | r（与性别） |
|--------|-------------|-------------|
| 总依恋 | −.21* | .06 |
| 可利用性 | −.15 | .02 |
| 愤怒苦恼 | −.29** | .10 |
| 目标矫正伙伴关系 | −.11 | .03 |
| 总攻击性 | −.39*** | .09 |
| 身体攻击 | −.36*** | .01 |
| 言语攻击 | −.32*** | −.06 |
| 愤怒（Anger） | −.26** | .19* |
| 敌意（Hostility） | −.32*** | .13 |
| 总心理病理 | −.43*** | .01 |
| 总自伤频率 | −.15 | .01 |

> *p < .05，**p < .01，***p < .001  
> **结论**：年龄与多数因变量显著相关，因此在主分析中作为协变量控制；性别仅与愤怒显著相关，故纳入调节分析。

## 四、主分析：多重偏相关分析（Table 5）

**多重比较校正**：共进行 30 次偏相关，采用 Bonferroni 校正，**显著性阈值设为 p < .002**（= .05/30）  
**方法**：所有偏相关均控制年龄和性别

### 4.1 生活史策略 × 家庭结构（3.2.1节）

| 家庭结构变量 | Mini-K pr | HKSS pr |
|-------------|-----------|---------|
| 全生物兄弟姐妹数 | .01 | .03 |
| 半同胞数 | −.10 | −.20 |
| 继兄弟姐妹数 | −.05 | −.08 |
| 继父母存在 | −.19 | −.06 |

> **结论**：所有相关均未达 Bonferroni 校正阈值（p < .002），**假设未获支持**。

### 4.2 生活史策略 × 总心理病理（3.2.2节）

| 变量 | Mini-K pr | HKSS pr |
|------|-----------|---------|
| **总心理病理** | **−.51** ✅ | **−.41** ✅ |
| 总自伤频率 | −.04 | −.17 |

> **结论**：生活史策略与总心理病理显著负相关（快策略→更多症状）；与自伤频率无显著相关。

### 4.3 生活史策略 × 依恋（3.2.3节）

| 依恋变量 | Mini-K pr | HKSS pr |
|---------|-----------|---------|
| **总依恋** | **−.42** ✅ | **−.41** ✅ |
| **可利用性** | **−.39** ✅ | **−.37** ✅ |
| **愤怒苦恼** | **−.44** ✅ | **−.44** ✅ |
| **目标矫正伙伴关系** | **−.39** ✅ | −.24 |

> **结论**：快速生活史策略与更不安全的依恋显著相关（快策略→依恋问题更多）。

### 4.4 生活史策略 × 攻击性（3.2.4节）

| 攻击性变量 | Mini-K pr | HKSS pr |
|-----------|-----------|---------|
| **总攻击性** | **−.46** ✅ | **−.43** ✅ |
| **身体攻击** | **−.44** ✅ | **−.34** ✅ |
| 言语攻击 | −.03 | −.10 |
| 愤怒（Anger） | −.31 | −.25 |
| **敌意（Hostility）** | **−.52** ✅ | **−.52** ✅ |

> **结论**：快速生活史策略与总攻击性、身体攻击、敌意显著正相关；言语攻击和愤怒未达校正阈值。

## 五、多元回归分析（Table 6）

**目的**：检验在控制年龄和家庭结构后，**依恋（感知父母支持）是否独立预测生活史策略**  
**方法**：多元线性回归，协变量 = 年龄、半同胞数、继兄弟姐妹数、全生物兄弟姐妹数；预测变量 = 总依恋

| 预测变量 | Mini-K b | Mini-K β | Mini-K t | HKSS b | HKSS β | HKSS t |
|---------|----------|----------|----------|--------|--------|--------|
| 年龄 | 0.21 | .27*** | 3.29 | 0.20 | .21* | 2.51 |
| 半同胞数 | −0.01 | .01 | −0.01 | −1.63 | −.10 | −1.21 |
| 继兄弟姐妹数 | 0.21 | .02 | 0.19 | 0.07 | .01 | 0.06 |
| 全生物兄弟姐妹数 | −0.04 | −.01 | −0.05 | 0.01 | .01 | 0.01 |
| **总依恋** | **−0.60** | **−.41***| **−5.20** | **−0.67** | **−.37***| **−4.68** |
| R² | .28 | | F(5,132)=10.49, p<.001 | .26 | | F(5,132)=9.09, p<.001 |

> *p < .05，***p < .001  
> **结论**：感知父母支持（依恋）是生活史策略的显著独立预测变量。依恋越不安全，生活史策略越快，且不受年龄和家庭结构的混淆影响。

## 六、调节分析（Moderation Analysis，×2）

**工具**：Hayes（2013）PROCESS 宏（条件过程分析）  
**协变量**：年龄  
**调节变量**：性别（男/女）

| 调节模型 | 自变量 | 因变量 | 调节变量 | 结果 |
|---------|--------|--------|---------|------|
| 模型1 | 生活史策略（Mini-K & HKSS） | 自伤频率 | 性别 | **❌ 无显著交互效应** |
| 模型2 | 生活史策略（Mini-K & HKSS） | 总攻击性（及各分量表） | 性别 | **❌ 无显著交互效应** |

> **结论**：性别在生活史策略对自伤或攻击性的影响中均未起到调节作用，假设未获支持。

## 八、核心结论

1. **快速生活史策略 → 更多心理病理症状**（DSM-5总分，两量表均显著）
2. **快速生活史策略 → 更不安全的依恋**（感知父母支持越低，策略越快）
3. **依恋是生活史策略的独立预测变量**（控制年龄和家庭结构后仍显著，R²=.26–.28）
4. **快速生活史策略 → 更高攻击性**（尤以身体攻击和敌意为主）
5. **生活史策略与自伤频率无显著关联**（不支持假设）
6. **性别调节效应均不显著**（不支持差异化假设）
7. **家庭结构（混合家庭/继父母）无显著预测效应**（不支持假设）
