## G. 唯一差异的详细分析

### ⚠️ 差异项：攻击性愤怒（Anger）分量表的偏相关

| | Mini-K × Anger | HKSS × Anger |
|---|---|---|
| **论文报告** | pr = −.31，**未达 p < .002** | pr = −.25，**未达 p < .002** |
| **复现结果** | pr = −.33，**p = .0001（显著）** | pr = −.27，**p = .0012（显著）** |
| **结论** | 论文：不显著 → 复现：显著 | 论文：不显著 → 复现：显著 |

**可能原因分析**：

1. **p 值临界敏感性**：论文 pr = −.31 和 −.25 的 p 值理论上约在 .001~.004 之间，非常接近 Bonferroni 阈值（.002）。复现 pr = −.33 / −.27 稍大（方向更强），p 值穿越了 .002 临界线。差异 Δpr = 0.02，极其微小。

2. **控制变量处理方式**：论文在偏相关中控制"年龄和性别"，但性别的编码方式未在正文中详细说明（可能使用哑变量、连续变量或不同参照组），这会导致偏相关系数的微小变化。

3. **四舍五入精度**：论文报告的相关系数精确到小数点后两位，实际 pr 可能介于 −.305 和 −.315 之间。在 Bonferroni 阈值附近，0.005 的精度误差足以导致显著性判断不同。

4. **结论层面的实质影响**：**不影响论文核心结论**。论文主要讨论的是快速生活史策略与攻击性（总分）、敌意、身体攻击的关联，愤怒分量表的结论在论文 Discussion 中并非关键论点。复现结果（愤怒也显著）甚至**强化了**论文的总体方向。
